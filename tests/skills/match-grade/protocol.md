## Вопросы автору → что изменилось

1. Нет `trailer.json`, сетка и рендер требуют проект, `edl` не может быть пуст. → `preview_grid.py` и `render_graded.py` получили режим `--clips a=… [--look] [--grade] [--out]`, как у `solve_grade.py` (общий разбор аргументов в `lib/montagelib/gradecli.py`, тесты `tests/test_grade_scripts.py`). `SKILL.md`, шаг 2; `looks.md`, «Режим клипов».
2. Решение по умолчанию даёт молочный нуар. → `SKILL.md`, шаг 4: признак «есть настоящий чёрный (картинка не молочная)»; шаг 5 включается и при молочной картинке; `looks.md`, «Молочный нуар и фиксированный контраст»: рецепт `--contrast <клип>=1.0` для тёмных сцен.
3. Как выбрать число `--contrast`, слово «группы». → `SKILL.md`, шаг 5: «фиксированный контраст, флаг на каждый клип», обычно 0.85–1.25, в `noir` тёмной сцене не ниже 1.0, смотреть `after std`; подробнее в `looks.md`. «Группы» убраны из навыка.
4. Что такое `before`. → `SKILL.md`, шаг 3; `looks.md`, «Как читать таблицу»; docstring `solve_grade.py`: замер после лука при 1.0/1.0.
5. Шкала цели 82. → `looks.md`, «Как читать таблицу»: полный диапазон 0–255, в `signalstats` YAVG это `16 + mean × 219/255` ≈ 86.4; docstring `solve_grade.py`.
6. Зачем разведка. → `SKILL.md`, шаг 1: из вывода нужны только раскадровки (какие клипы — одна сцена).
7. Имена копий `c2_noir_c2.mp4`. → `render_graded.py`: при алиасе, равном имени файла, — `<имя>_<лук>.mp4`, иначе прежнее `<алиас>_<лук>_<имя>.mp4` (тест `test_render_graded_clip_mode`). `SKILL.md`, шаг 6; `looks.md`.
8. Режим без проекта пишет в текущую папку. → `SKILL.md`, шаг 2 («без `--out` всё ложится в текущую папку»); `looks.md`, «Режим клипов»; docstrings трёх скриптов.
