# Единый грейд

Лук один на весь фильм, а клипы приходят разной яркости. Поэтому у каждого клипа свои `eq=gamma:contrast` до лука, лук после них общий. Гамму и контраст подбирает решатель по замеру после всей цепочки; глаз только проверяет.

В командах ниже `PY` = `${LEO50S_HOME:-$HOME/.cache/leo50s-montage}/venv/bin/python`, `D` = папка этого навыка (печатается при загрузке), `T` = путь к `trailer.json`. Shell не хранит переменные между вызовами: подставляй полные пути в каждую команду. Нет venv ⇒ `bash $D/../../scripts/setup_env.sh --no-whisper`.

## Результат работы (контракт)

1. Разведка: `$PY $D/../trailer-build/scripts/probe_clips.py <папка клипов>` → длительность, размер, fps, уровни звука; раскадровки в `<папка>/_probe/`, посмотри их через Read.
2. В `T` есть `clips` и `look` (`noir` по умолчанию; луки и как добавить свой — `references/looks/looks.md`). Поля `grade` до первого решения нет: файла ещё нет, и загрузка проекта упадёт.
3. Решение: `$PY $D/scripts/solve_grade.py $T` → таблица `before/after mean/std, gamma, contrast` и `gammas.txt` рядом с `T`. Пропиши в `T` `"grade": "gammas.txt"`.
4. Проверка глазом: `$PY $D/scripts/preview_grid.py $T --t 4` → `out/grade_grid.jpg`, исходник сверху, грейд снизу. Открой через Read. Тени не провалены, света не выбиты, цвета нет, клипы одной сцены одинаково плотные. Плохой кадр ⇒ другой момент: `--t 8`.
5. Сцены должны различаться плотностью (интерьер контрастнее, улица мягче) ⇒ группы контраста, по флагу на клип: `$PY $D/scripts/solve_grade.py $T --contrast c2=1.22 --contrast c1=0.86`. Контраст фиксирован, решается только гамма. Затем снова шаг 4.
6. По запросу полные копии со звуком: `$PY $D/scripts/render_graded.py $T` → `graded_<лук>/<алиас>_<лук>_<имя>.mp4`.
7. Трейлер уже собирался ⇒ пересобери картинку, один шаг за вызов: `$PY $D/../trailer-build/scripts/build.py $T segments`, затем тем же скриптом `assemble`, `mux`, `preview`.

Без проекта, только клипы: `$PY $D/scripts/solve_grade.py --clips a=<путь> b=<путь> --look noir --out <папка>/gammas.txt`.

## Готово, когда

- solve_grade вышел с кодом 0: средняя яркость каждого клипа после грейда в ±2 от цели (82 из 255 по умолчанию, `--target-mean`). Строка `warning:` — не готово: проверь клип в сетке, ослабь его группу контраста.
- Сетка после последнего решения открыта через Read.
- Сменился лук или группы контраста ⇒ решение заново: старые гаммы к новой кривой не подходят.

## Отдаёшь

1. `gammas.txt` и строку `"grade"` в `trailer.json`.
2. Таблицу solve_grade: до и после, гамма, контраст по каждому клипу.
3. `out/grade_grid.jpg` и что на ней видно.
4. Копии из render_graded, если просили.
5. Допущения отдельным абзацем: какие группы контраста выбраны и почему.

## Красные флаги

- Гамма подобрана на глаз или вписана руками в `gammas.txt`.
- «Выглядит ровно», а таблицы solve_grade в ответе нет.
- `eq=gamma` дописан в файл лука.
- После смены лука сегменты пересобраны со старым `gammas.txt`.
