# Формат trailer.json

Один файл описывает весь трейлер: клипы, грейд, монтажный лист (`edl`), партитуру (`score`)
и выход. Папка, где лежит `trailer.json`, — папка сборки: там появляются `seg/`, `cards/`,
`wav/`, `out/`. Все относительные пути считаются от неё, кроме пути к луку. `load_project` проверяет файл целиком
и печатает все ошибки разом; шаг `build.py <trailer.json> edl` — самая быстрая проверка.

Время. Все `d` и `ov` прилипают к сетке кадров. Стык `cut` — перекрытие в один кадр, `ov`
у него игнорируется; у первого сегмента перекрытия нет. «Момент сегмента» (куда встают удары,
от и до каких звучат слои) — визуальное начало: начало сегмента при `cut`, середина
перекрытия при `fade`/`fadewhite`. `edl` печатает начала сегментов и `total`.

## Верхний уровень

| поле | тип | по умолчанию | смысл |
|---|---|---|---|
| `clips` | объект `{алиас: путь}` | `{}` | исходники; путь от папки сборки, обычно `../файл.mp4` |
| `fps` | целое > 0 | `24` | частота кадров трейлера |
| `size` | `[ширина, высота]` | `[1920, 1080]` | размер кадра |
| `letterbox` | целое ≥ 0 или `null` | `null` | высота чёрных полос сверху и снизу, px; `null` и `0` — без полос; 138 даёт 2.39:1 в 1080p |
| `look` | строка | `"noir"` | имя лука из `match-grade/references/looks/` или путь к `.txt`; относительный путь считается от текущей папки, а не от папки сборки — пиши абсолютный |
| `grade` | строка или `null` | `null` | файл грейда `алиас гамма контраст` (пишет `solve_grade.py`); без него у всех 1.0/1.0 |
| `fonts` | объект `{card, title}` | HelveticaNeue.ttc#1, DIN Condensed Bold.ttf | шрифты карточек и названия; `путь#N` — N-е начертание в коллекции |
| `edl` | список сегментов | обязателен, не пуст | монтажный лист, по порядку |
| `score` | объект | `{}` | партитура: `layers`, `hits`, `master` |
| `output` | объект | `{"name": "trailer", "crf": 16, "preview_height": 720}` | `out/<name>.mp4`, качество сборки x264, высота превью `out/<name>_<h>p.mp4` |

## Сегмент (`edl[]`)

| поле | тип | по умолчанию | смысл |
|---|---|---|---|
| `id` | строка | обязателен | уникальный, на него ссылаются шаги, слои и `whistle_from` |
| `kind` | `clip` `card` `title` `black` `white` | обязателен | кадр из клипа, текстовая карточка, название, чёрное, белое (держится и гаснет в чёрное) |
| `d` | число > 0 | обязателен | длина на таймлайне, с |
| `ov` | число, `0 ≤ ov < d` | `0` | перекрытие с предыдущим сегментом, с |
| `trans` | `fade` `fadewhite` `cut` | `fade` | вход в сегмент: растворение, через белое, стык |
| `src` | алиас | `null` | клип; обязателен для `clip` |
| `ss` | число | `0` | откуда брать в исходнике, с (у `title` с `bg: clip` — начало фона) |
| `fx` | список или строка | `[]` | `push` медленный наезд, `shake` тряска, `slow2`/`slow4` замедление в 2/4 раза |
| `shake` | число | `1.0` | амплитуда тряски, доля от полной; в атаке примера 0.3 |
| `speech` | логическое | `false` | в сегменте реплика: музыка уходит под `duck`, звук клипа на полную; проверяют check_cuts и verify_mix |
| `duck` | число | `0.5` | уровень музыки под репликой (скаты 0.25 с) |
| `amb` | число или `null` | `null` | громкость звука клипа; `null` — 1.0 при `speech`, иначе `master.ambience_default`; у `slow*` звука нет |
| `hit` | строка или объект | `null` | удар в момент сегмента, см. ниже |
| `text` | строка | `null` | текст карточки или названия |
| `lines` | список `[текст, кегль]` | `null` | многострочная карточка, заменяет `text` |
| `small` | логическое | `false` | мелкая карточка: кегль 50 вместо 58, уход 0.5 с |
| `style` | `plain` `painted` | `plain` | у `title`: набранное или рисованное с потёками и слэмом |
| `bg` | `black` `clip` | `black` | фон рисованного названия |
| `bg_src` | алиас | `null` | клип фона при `bg: clip` (обязателен тогда) |
| `fade_in` | число | `0` | у `clip`: проявление из чёрного, с |

## Удар (`hit`)

Строка `"boom"` равна объекту `{"type": "boom"}`.

| поле | тип | по умолчанию | смысл |
|---|---|---|---|
| `type` | `boom` `bigboom` `braam` `hit` `riser` `explosion` `titleboom` | обязателен | вид удара (см. `synth-score/references/instruments.md`) |
| `gain` | число или `null` | `null` | громкость; `null` — из `score.hits`, затем из умолчаний |
| `offset` | число | `0` | сдвиг от момента сегмента, с; у `explosion` не действует |
| `whistle_from` | id сегмента или `null` | `null` | у `explosion`: свист бомбы от момента этого сегмента + 0.1 до белого кадра |

`explosion` бьёт в начало сегмента + 0.3 с (момент полного белого). `riser` длиной `d − 0.15`
идёт в музыкальную шину и приглушается под речью.

## Слой партитуры (`score.layers[]`)

| поле | тип | по умолчанию | смысл |
|---|---|---|---|
| `instrument` | `drone` `heartbeat` `ticks` `ostinato` `riser` `whistle` | обязателен | инструмент |
| `from` | id | обязателен | начало: момент сегмента |
| `to` | id или `"end"` | обязателен | конец: момент сегмента; `end` = `total + 0.5` |
| `gain` | число | `1.0` | постоянная громкость (игнорируется при `ramp`) |
| `ramp` | список `[id, громкость]` | нет | громкость по точкам-моментам, линейно; за крайними точками держится |
| `attack` | число | `3.0` | нарастание в начале, с; `0` — сразу |
| `release` | число | `0.4` | затухание в конце, с |
| `trim_end` | число | `0.0` | закончить раньше `to` на столько секунд |
| `params` | объект | `{}` | параметры инструмента, только из его сигнатуры (`bpm`, `gap`, `pattern`) |

## `score.hits` и `score.master`

`score.hits` — `{тип: громкость}` поверх умолчаний: boom 0.75, bigboom 1.0, braam 0.7,
hit 0.55, riser 0.3, titleboom 0.7, explosion 1.0.

| поле | тип | по умолчанию | смысл |
|---|---|---|---|
| `speech_rms` | число | `0.09` | звук каждого клипа приводится к этому RMS (около −21 dBFS, усиление не больше ×8) |
| `ambience_default` | число | `0.35` | громкость звука клипа без реплики |
| `target_peak` | число | `0.92` | пик мастера после мягкого лимитера |
| `fade_out` | число | `1.2` | затухание в конце, с |

## Правка → поля → шаги

Шаги — `build.py <trailer.json> <шаг> [ids]`, один шаг за вызов, по порядку.

| правка пользователя | поля | шаги для перезапуска |
|---|---|---|
| другой текст карточки или названия | `text`, `lines`, `small`, `style` | `segments <id>` (перерисует карточку), `assemble`, `mux`, `preview` |
| длина сегмента | `d` | `segments <id>`, `film`, `assemble`, `audio`, `mux`, `preview` |
| граница реплики | `ss`, `d` (по `speech-safe-cuts`) | `segments <id>`, `film`, `assemble`, `audio`, `mux`, `preview`, затем check_cuts и verify_mix |
| другой кадр из того же клипа | `ss`, `src` | `segments <id>`, `assemble`, `audio`, `mux`, `preview` |
| переход, перекрытие | `trans`, `ov` | `film`, `assemble`, `audio`, `mux`, `preview` |
| тряска, наезд | `fx`, `shake` | `segments <id>`, `assemble`, `mux`, `preview` |
| слоу-мо | `fx` (`slow2`/`slow4`) | `segments <id>`, `assemble`, `audio`, `mux`, `preview` |
| громче или тише музыка, другие слои | `score.layers` | `audio`, `mux`, `preview` |
| удар добавить, убрать, громкость | `hit`, `score.hits` | `audio`, `mux`, `preview` |
| реплику не слышно, звук клипа | `duck`, `amb`, `speech` | `audio`, `mux`, `preview`, затем verify_mix |
| другой лук или контраст | `look`, затем `grade` (`solve_grade.py`) | `segments`, `assemble`, `mux`, `preview` |
| новый клип | `clips`, затем `grade` (`solve_grade.py`) | `wav`, `segments`, `assemble`, `audio`, `mux`, `preview` |
| полосы, размер, fps | `letterbox`, `size`, `fps` | `all` |
| имя файла, качество | `output` | `assemble` (только `crf`), `mux`, `preview` |

После любой правки длины `edl` печатает новый `total`; кадров в `out/<name>.mp4` должно
быть `round(total × fps)`.
